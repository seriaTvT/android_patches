    libutils: rate-limit RefBase explicit-destruction backtrace

    RefBase::~RefBase() logs a full symbolized CallStack every time an object
    is explicitly destroyed while its weak count is non-zero. Capturing that
    stack unwinds and decompresses each frame's .gnu_debugdata (LZMA), which is
    expensive. Vendor blobs that trip this on a hot path make it pathological:
    MediaTek's libgpu_aux GuiExtAuxBufferQueue teardown, reached from
    eglDestroyImageKHR once per rendered frame, pegs the GPU thread on stack
    unwinding and causes severe UI stutter during media playback.

    Emit the diagnostic backtrace at most once per process; the one-line ALOGW
    still fires every time so the misuse stays visible.
